# Changelog

## 0.1.0 — Initial public release

- Generalized the prior-art research workflow into configurable study claims and criteria.
- Added isolated workspace initialization and one-time control freezing.
- Retained query genealogy, bounded API retrieval, discovery-preserving ingestion, evidence review, and matrix generation.
- Added synthetic offline examples, acceptance tests, documentation, and CI configuration.
- Added MIT licensing and private-workspace defaults.

This is a toolkit release, not a release of an underlying research study or a claim that every live provider integration has been certified.

- Added a bounded Eytzinger literature-search case study with live retrieval receipts, primary-evidence comparison, pending review, and explicit coverage limits.
- Added offline snapshot verification and deterministic replay.
